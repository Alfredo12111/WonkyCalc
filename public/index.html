      A SMALL FIELD GUIDE
      
    Meet your overqualified calculator.
    
      
    
        Type expressions normally, then press Enter or
        =. Twelve native workers take your expression on a
        trip; Haxe runs the interface. Every calculation first rebuilds Mercury,
        Eiffel and Icon. Each operation gets Eiffel checks before and after, and
        Factor and Rexx always attempt independent checks. Open a language row,
        operation graph, or receipt to inspect what actually happened. The extra
        work is automatic, so even simple sums take a while.
      
    
      
    
        
    Scientific
    
        
    
          sqrt(81), 2^10, 5!,
          ln(e), log(100), logn(8,2),
          root(27,3), ncr(52,5)
        
    
        
    Trigonometry
    
        
    
          sin, cos, tan and their
          inverses use the selected DEG/RAD mode. Hyperbolic functions always
          use dimensionless arguments.
        
    
        
    Statistics
    
        
    
          Comma-separated arguments: mean(2,4,6),
          median(3,1,8), stdev(1,2,3),
          variance(1,2,3). Standard deviation and variance are
          population statistics. Maximum 64 arguments.
        
    
        
    Arrays & units
    
        
    
          dot([1,2,3],[4,5,6]),
          matmul([[1,2],[3,4]],[[5,6],[7,8]]),
          det([[1,2],[3,4]]), transpose,
          norm, and array sums/means/min/max. Rectangular arrays
          have at most two dimensions and 256 elements; determinants are at most
          6×6. Add units with 5 m + 30 cm or
          10 m / 2 s. Supported: m, cm, km, kg, g, s, ms, seconds.
          Results use metres, kilograms and seconds. Mercury rejects
          incompatible dimensions.
        
    
        
    Small print, actual math
    
        
    
          Use explicit multiplication: 2*pi. Exponents are
          right-associative; -2^2 = -4. Postfix
          % divides by 100, so 200+10% = 200.1.
          mod(a,b) is modulo. atan2(y,x) follows that
          argument order.
        
    
        
    Precision & limits
    
        
    
          Real-number arithmetic with roughly 15–16 significant digits
          internally. Display rounding does not change Ans or stored memory.
          Factorials and combinatorics accept integers through 170. Complex
          numbers, symbolic algebra, and graphing are outside this version.
        
    
        
    Keyboard & memory
    
        
    
          Enter calculates, Escape clears. ans recalls the
          full-precision last dimensionless scalar answer. MS stores it, MR
          inserts memory, and M+/M− run a new calculation. Array and unit
          results are available in history and through Copy; they leave scalar
          memory and Ans unchanged. History and memory stay in this browser.
        
    
        
    The independent opinions
    
        
    
          Factor and Rexx always read Raku's instruction stream independently.
          Unsupported functions are labelled, never silently borrowed from J.
          Rexx uses 50 decimal digits for its supported arithmetic; repeating
          fractions are still rounded. Its difference from J is shown as a
          decimal string.
        
    
        
    The receipt
    
        
    
          Worker launches count direct worker process invocations, including the
          Python host for Tcl. Payload bytes count worker input and output data
          files, including generated J plans and excluding installed worker
          source. Numeric time is measured inside J/BQN; the remaining worker
          time includes startup, file I/O and independent checks. Rebuilding is
          timed separately; compiler subprocesses are not included in the worker
          count.

A SMALL FIELD GUIDE

Meet your overqualified calculator.

Type expressions normally, then press Enter or =. Every successful calculation really runs through all six languages. Open any completed language row to see what it produced.

Scientific
sqrt(81), 2^10, 5!, ln(e), log(100), logn(8,2), root(27,3), ncr(52,5)
Trigonometry
sin, cos, tan and their inverses use the selected DEG/RAD mode. Hyperbolic functions always use dimensionless arguments.
Statistics
Comma-separated arguments: mean(2,4,6), median(3,1,8), stdev(1,2,3), variance(1,2,3). Standard deviation and variance are population statistics. Maximum 64 arguments.
Small print, actual math
Use explicit multiplication: 2*pi. Exponents are right-associative; -2^2 = -4. Postfix % divides by 100, so 200+10% = 200.1. mod(a,b) is modulo. atan2(y,x) follows that argument order.
Precision & limits
Real-number arithmetic with roughly 15–16 significant digits internally. Display rounding does not change Ans or stored memory. Factorials and combinatorics accept integers through 170. Complex numbers, symbolic algebra, and graphing are outside this version.
Keyboard & memory
Enter calculates, Escape clears. ans recalls the full-precision last answer. MS stores it, MR inserts memory, and M+/M− run a new six-language calculation. History and memory stay in this browser.
